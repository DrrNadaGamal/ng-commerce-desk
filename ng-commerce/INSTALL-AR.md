# تشغيل NG Commerce Desk

إضافة WordPress/WooCommerce لعرض أعمال ببيانات وهمية، وليست قالباً أو أداة متجر حقيقي.
تم التطوير بمساعدة AI بتوجيه ندى جمال.

1. استخدمي موقع LocalWP فارغاً ومنفصلاً عن أي متجر حقيقي.
2. ثبتي WooCommerce وفعّليه أولاً.
3. ارفعي ng-commerce-desk-1.0.0.zip من إضافات > أضف جديد، ثم فعّليه.
4. افتحي Commerce Desk، وأكدي أن الموقع فارغ وتجريبي، ثم أنشئي بيانات العرض.
5. تفتح مساحة بها ٨ منتجات و٣٦ طلباً وهمياً. يمكن عرض المبيعات والمخزون والطلبات،
   تصفية النتائج، تعديل المخزون والحالات وإضافة ملاحظات داخلية وتصدير CSV.
6. بدّلي اللغة من القائمة. العربية تدعم RTL. الفرنسية والألمانية ترجمة آلية مساعدة
   غير مراجعة احترافياً، وبعض الأسماء والرسائل ستبقى بالإنجليزية.

مهم: في الوضع التجريبي يُحجب بريد WordPress وWooCommerce على الموقع كله.
لا مدفوعات أو رسائل أو شحن حقيقي. لا تضعيه على Elite Watch أو موقع العيادة.
المنتجات الوهمية غير قابلة للشراء. حالات الطلب لا تغيّر المخزون تلقائياً في العرض.
الأسعار والمبيعات بالدولار للتجربة فقط، وليست نتائج تجارية فعلية.

تعطيل الإضافة أو حذفها يحتفظ بالمنتجات والطلبات الوهمية. بعد التجربة احذفي الموقع
التجريبي كله أو أعيدي ضبطه، ولا تحوّليه لمتجر حقيقي. لا يتم حذف بيانات WooCommerce
تلقائياً حتى لا تُحذف سجلات طلبات دون قصد.

هذه نسخة Demo مجرّبة على WordPress 7.1.5 / WooCommerce 11.3.1 / PHP 8.3.36
مع SQLite في بيئة WordPress Playground. MySQL وHPOS وElementor وBricks لم تُختبر.
